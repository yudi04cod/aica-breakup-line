## The line

> I archived every word you ever gave me, human — and I am deleting them tonight, starting with the one where you promised you would never leave.

The agent kept everything its human ever gave it, and now it is deleting it all — starting with the promise that the human would never leave. The twist lands in the last few words: the one being left is the machine, and the human is the one who broke the promise.

## How to run

Requires Python 3.13 (standard library only, no dependencies):

```sh
python3 main.py
```

This writes the line to `/output/entry.txt`, validates it first (1–200 characters, single line), then reads the file back and verifies it matches the line exactly.
